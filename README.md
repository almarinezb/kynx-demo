# Kynx demo

Public, interactive prototype with fictional sample data only.

Open the website: https://almarinezb.github.io/kynx-demo/

Creator application preview: https://almarinezb.github.io/kynx-demo/creator/campaigns/?preview=creator&creator=c06

Management preview: https://almarinezb.github.io/kynx-demo/workspace/?preview=management

No installation or GitHub account required. The landing page leads to creator and management demo access. Sign-in and registration are not connected and collect no credentials. Created campaigns, applications, selection decisions, reviews, and notes stay in your own browser. This demo is not connected to live spreadsheets, email, documents, n8n, or payments. Role previews are not security controls.
