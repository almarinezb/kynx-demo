# Kynx demo

Public, interactive prototype with fictional sample data only.

Open the website: https://almarinezb.github.io/kynx-demo/

No installation or GitHub account required. The demo previews staff roles and a creator application journey. Created campaigns, applications, selection decisions, reviews, and notes stay in your own browser. This demo is not connected to live spreadsheets, email, documents, n8n, or payments. Role previews are not security controls.
